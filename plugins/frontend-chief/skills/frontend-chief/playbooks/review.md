# レビュー

入力：対象差分または設計、目的、既存の検証結果。
1. [調査](../../assess-frontend/SKILL.md)で意図と呼出し元を確認する。必要な範囲だけ読む。
2. [レビュー](../../review-frontend/SKILL.md)で変更に関係する原則と[観点表](../../../references/review-checklist.md)を適用する。
3. 再現・確認が必要な指摘だけ[検証](../../verify-frontend/SKILL.md)を行う。
4. 重要度・根拠・影響・修正案、未確認を分けて報告する。

出力：指摘または指摘なしと範囲。仕様不明の懸念は条件付き。完了：採否を判断できる報告。修正の依頼なしにコードを書き換えない。
