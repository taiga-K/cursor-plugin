# 新規構築

適用：新規Go API、標準導入。

## 工程

1. [調査](../../assess-backend/SKILL.md)で既存資産と業務要件を確認する。
2. [setup](../../setup-backend/SKILL.md)で採用技術とDBを決め、最小の業務経路と検証基盤を構築する。判断と実行手順は対象の管理方法に合わせて記録する。
3. [レビュー](../../review-backend/SKILL.md)で契約、責務、認可、選択DBの保証を確認する。
4. [検証](../../verify-backend/SKILL.md)の証拠とインフラへの未充足条件を報告する。

## 完了時の成果

最小の業務経路、採用版・DB選択、再現可能な検証、引き渡し条件。

[共通形式](../../../references/output-contracts.md)に従う。省略した工程と未検証は理由を残す。
